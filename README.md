# Dongwoo Lee - Neumorphism Portfolio

Personal GitHub Pages site for Dongwoo Lee.

This site is based on Longpdo's `neumorphism` Jekyll theme and customized as an academic AI research portfolio.

## Deploy to GitHub Pages

Use the repository:

```text
merrybabyxmas.github.io
```

Copy these files to the repository root, commit, and push. Set GitHub Pages to deploy from the `main` branch root or use GitHub's default Pages build for Jekyll.

## Content files

- `_config.yml`: site title, social links, section toggles, and long-form bio
- `_data/projects.yml`: publications and research projects
- `_data/timeline.yml`: education and experience
- `_data/skills-*.yml`: skills shown in the skills section

## Local preview

This is a Jekyll site. To preview locally, install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

The GitHub Pages environment can build the site without committing generated `_site` output.
